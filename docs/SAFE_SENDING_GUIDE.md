# Safe Sending Guide

This framework is designed for controlled, low-volume and targeted outreach.

Recommended controls:

- Send one email per recipient.
- Do not use BCC blasting.
- Keep random delay between emails.
- Keep daily limit.
- Stop after repeated failures.
- Do not send duplicates.
- Use a dedicated job-search email account.
- Use dry run before real sending.
- Keep content simple, accurate, and non-misleading.
